# Data and evidence policy

For each dataset/output, record provider, dataset/product/collection and version; original URL/catalog ID and access date; acquisition/valid time and timezone; spatial/temporal resolution; bands, scale factors, nodata and units; CRS and reprojection/resampling; method and parameters; missing-data/cloud-mask handling; software version; validation and uncertainty.

Never silently substitute a forecast for an observation, cached data for current data, regional map for a lot-level measurement, or illustrative layer for a processed result. Label fallbacks clearly.

Prefer official catalogs and documentation. Candidate providers include Copernicus Data Space, USGS EarthExplorer, NASA POWER, Open-Meteo, national meteorological services, geographic institutes and agricultural research institutes. Verify coverage, license, terms and availability for each dataset and task.
