# Roadmap

## v0.1 foundation
- [x] Modular assistant entry point and execution-mode contract.
- [x] Dependency-free GeoJSON structural validation.
- [x] NDVI/NDWI normalized-difference helpers.
- [x] Basic GDD and rainfall calculations.
- [x] CLI, tests, examples and CI.

## v0.2 data workflows
- [ ] Optional Shapely/pyproj reprojection and topology validation.
- [ ] Raster metadata inspection and masking with Rasterio.
- [ ] Reproducible Sentinel-1/2 and Landsat discovery/download adapters.
- [ ] CSV weather ingestion with timezone/missing-data validation.
- [ ] Provenance sidecar JSON for generated outputs.

## v0.3 decision support
- [ ] Management zones with ground-truth requirements.
- [ ] Crop-specific phenology models with local calibration.
- [ ] Forest monitoring and change-detection workflows.
- [ ] Prescription-map schema validation and export tests.

## v1.0
- [ ] Opt-in integration adapters.
- [ ] End-to-end tests with openly licensed sample data.
- [ ] Benchmarks, reproducibility tests and uncertainty documentation.
- [ ] User testing on phone, desktop, ChatGPT Free and Pro.

Roadmap items are goals, not claims of implemented functionality.
