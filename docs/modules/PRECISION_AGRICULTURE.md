# Precision agriculture

A defensible variable-rate workflow requires more than an index map.

1. Define objective: seed, fertilizer, lime, irrigation, scouting or harvest.
2. Gather field boundaries, yield/soil/elevation/imagery data, history and constraints.
3. Align dates, CRS, pixel sizes, units and spatial support.
4. Explore patterns and stable zones across seasons where possible.
5. Validate with soil sampling, scouting, yield data or ground truth.
6. Convert validated decisions to an equipment-compatible prescription schema.
7. Check geometry, units, rates, machine width, controller compatibility and local requirements.

Never derive application rates solely from NDVI or generic thresholds. Recommendations require crop, stage, soil tests, product, equipment calibration, local regulation and qualified agronomic review.
